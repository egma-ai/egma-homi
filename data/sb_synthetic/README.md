# sb_synthetic

Real vs synthetic speech: half the clips are original human recordings, half come from five TTS systems or from
copy-synthesis of real recordings through two neural vocoders.

## Questions
- Yes/no ("Is this a real person speaking?", "Was this voice generated by a computer?"; 50/50), real-or-synthetic
  choice, and pairs of one real and one synthetic clip (which voice is synthetic / real).
- Labels come from the pipeline that made the clip. TTS clips read real clips' transcripts, both classes get the same
  augmentation and codecs, and durations are histogram-matched. CAL uses held-out speakers, meetings and TTS voices.

## Run
    modal run --detach data/sb_synthetic/modal_build.py::run_prep   # real pool (CPU)
    modal run --detach data/sb_synthetic/modal_build.py::gpu        # Parler-TTS and Chatterbox on one L4 GPU
    modal run --detach data/sb_synthetic/modal_build.py::full       # CPU synthesis, waits for ::gpu, writes items

Writes `/vol/stageb/sb_synthetic/` on the `homi` volume: `items_train.jsonl`, `items_cal.jsonl`, `audio/`,
`summary.json`.
